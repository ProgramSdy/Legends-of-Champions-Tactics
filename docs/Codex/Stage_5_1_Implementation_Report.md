The approved 1897×868 windowed Laptop Large reference was reproduced in an isolated no-save Debug battle. The actual Battlefield was 1351×560 CSS px. BG03 is 1536×1024 source pixels, rendered by `cover` at scale `max(1351/1536, 560/1024) = 0.87956`: 1351×900.7 CSS px, cropped about 170.3 px at both top and bottom. The old hero rate was `0.7`; a Mage Comprehensiveness 1v1 figure had formation×individual multiplier `1.5×0.9=1.35`, art width `172×1.35×0.7=162.54` CSS px and hit width `157.81` CSS px. The implemented rate is `0.7 × currentCoverScale / referenceCoverScale` for the selected background, with cover measured from the actual Battlefield content rectangle and its image dimensions. `ResizeObserver` and the existing resize/mode signals update it after container or HUD-mode changes. The same CSS rate drives the figure/its bounded hit area, overhead HP clearance, duel HP sizing, and target-preview anchor. `assets.ts` hero multipliers and `formations.ts` x/y, depth and formation multipliers are untouched. BG01/BG02/BG03 source dimensions are registered; a custom image is measured on load. Each background is calibrated to the same *reference field and hero rate*, not presumed to have identical logical scene pixels. Per-art camera/landmark calibration would require visual approval.
